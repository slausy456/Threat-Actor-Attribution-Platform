# Data directory

- `veridark/` — place the published VeriDark benchmark files here (not committed;
  see `.gitignore`). Download instructions to be added once the team accesses it.
- `processed/` — cleaned/derived data produced by our pipeline, generated from
  the above. Not committed.
- `raw/` — any other published, legal research dataset drops (e.g. VendorLink /
  PGP-correlation released data). Not committed.

**Nothing in this directory should ever be data collected via live scanning of
real Tor hidden services or dark web marketplaces.** See
`../docs/ethics_and_data_sources.md`.
